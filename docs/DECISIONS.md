# Решения с датами и причинами

## 26.10.2026 — Вакансия
Позиция AI Game Designer в Azur Games (Роман называет её AI Game Creator). Главное требование, которое закрывает проект: «ежедневно пользоваться Claude Code или Codex и показать готовый пример — билд, репозиторий или видео». Подробности — `docs/BRIEF.md`.

## 26.10.2026 — Игра: Stack Ball
**Почему:** второй по загрузкам хит Azur (560 млн, данные компании), рекламируется прямо сейчас (5 из 26 самых показываемых объявлений Azur в Meta, запуск 28.09.2026), механика в одно касание укладывается в 25 секунд, у Azur есть история с плейблом этой игры (кейс ironSource 2019: первый плейбл проиграл видео, улучшенный выиграл).
**Отказались:** Worms Zone (в топе Meta не найдена, нужны соперники с ИИ), стратегия «Get ready for battle» (слишком тяжёлая для демо), Sponge Art (сложная физика губки).

## 26.10.2026 — Концепция: B «Спаси котика»
**Решил Роман**, по совету ИИ. Механика Stack Ball плюс сюжет: котик в клетке внизу, шипы сверху. Крючка «спаси» нет в текущей рекламе Stack Ball; похожий приём Azur сейчас использует в Claw Master. A «Классика» — контроль в тесте, C «Выбери шар» — третий вариант.
**Риск:** котика нет в самой игре, поэтому в тесте обязательно смотреть удержание D1.

## 26.10.2026 — Это не копия
В отделе плейблы делают для живых игр компании. Копия — пересобрать их видео один в один. Наш плейбл — тот же геймплей плюс новая гипотеза, которую можно проверить.

## 26.10.2026 — Оформление документов: стиль «Сетка»
Свободное направление B из `design-base/STYLES.md`: белый, чёрный, сигнальный жёлтый #FFD400, шрифт Onest. Жёлтый с чёрным перекликается с башней Stack Ball. Роман не возражал. Без нумерации 01/02, без маркеров в текстах интерфейса, без сине-фиолетовых градиентов (`design-base/TASTE.md`).

## 26.10.2026 — Внешний вид плейбла: как у Stack Ball
Плейбл — реклама чужого бренда, поэтому характер берём у игры (как правило «Si Phone — сохранять бренд» в design-base): яркие градиенты, цветная башня с чёрными секторами, полоса уровня со счётом, шахматная платформа финиша. Стиль «Сетка» к самому плейблу не относится.
**Исключение из вкуса Романа:** в рекламе подсказка-рука должна быть заметной (правило жанра, подтверждено кейсом Playworks), хотя в его продуктах подсказки тихие.

## 26.10.2026 — Технологии
Three.js (3D) + Vite + vite-plugin-singlefile: сборка в один HTML, всё внутри, без внешних запросов (требование сетей). Шрифты системные. Звуки синтезируются WebAudio — без файлов и без прав на чужие звуки. Котик и клетка собраны из простых 3D-фигур — быстро и без ассетов. Unity и Luna Playworks не берём: за день быстрее и легче на чистом вебе, а итог тот же — HTML5-билд.

## 26.10.2026 — Баланс шипов и попыток
Первая версия (скорость 1,0) убивала игрока, который держит палец треть времени. Снизили до 0,8 и добавили «догоняние»: шипы всегда в кадре, но опасны только медленным. Вторая попытка на 20% легче, после второй неудачи — сразу end card (в рекламе не держим человека в бесконечных попытках). Страховка: end card через 40 с после первого касания.

## 26.10.2026 — Камера на котике
В интро и после спасения камера подлетает к котику крупным планом, во время игры — обычный вид сверху, как в Stack Ball. Котик после спасения прыгает лицом к игроку, а не крутится.

## 26.10.2026 — Язык плейбла
По умолчанию английский (реклама для мировых рынков), русский по `?lang=ru`.

## 26.10.2026 — Этап 3: вариант C и показ «смотри, потом играй»
C = B + выбор шара (а не классика + выбор), чтобы от основного варианта отличалась ровно одна вещь. У каждого шара одно понятное свойство, видно с первого удара.
Показ сделан флагом `?demo=1`, а не отдельным видео: это тот же HTML, вес не растёт, и его можно включить к любому варианту. Роман спросил про рекламу «сначала видео, потом играешь» — это отдельный формат (видео + интерактивная концовка), наш плейбл может быть такой концовкой после их текущего видео.
Режим огня теперь работает как в оригинале: только пока держишь палец. Иначе огненный шар проходил уровень за секунду.

## 26.10.2026 — Страница вариантов вместо отдельной «демо-страницы» на этапе 4
Переключатели вариантов, показа и языка, телефон с игрой и живая воронка событий собраны на одной странице `demo/` уже на этапе 3 — Роман любит выбирать из вариантов прямо на странице. На этапе 4 она станет частью публичной ссылки.
