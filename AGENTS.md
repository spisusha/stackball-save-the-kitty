# Инструкция для ИИ-помощника (Claude, Codex, Cursor и др.)

## О проекте
Playable-креатив «Спаси котика» для игры Stack Ball (Azur Games) — неофициальный концепт к собеседованию Романа на позицию AI Game Designer в Azur Games. Начат 26.10.2026.

Прочитай перед работой: `README.md` → `docs/PLAN.md` (текущий этап и статус) → `docs/BRIEF.md` (запрос и ТЗ) → `docs/SPEC.md` (сценарий, баланс, события, требования сетей) → `docs/DECISIONS.md` (почему так) → `docs/RESEARCH.md` (факты и источники).

## Как работать с Романом
- Пиши по-русски, просто и коротко, без жаргона. Роман не программист по профессии.
- Работаем по этапам: этап делается целиком → показывается вживую (страница в браузере) → Роман одобряет или просит правки. Не перескакивай этапы.
- Любит выбирать из 2–4 вариантов с переключателем прямо на странице.
- Мобильная версия — приоритет: проверяй ширину 375 px, без горизонтальной прокрутки.
- Честно: не выдумывай цифры и факты, непроверенное помечай.
- После каждого решения обновляй `docs/PLAN.md` (статус и журнал) и `docs/DECISIONS.md`.

## Команды
```
npm install          # один раз
npm run dev          # плейбл в режиме разработки: http://127.0.0.1:5174/game/
npm run build        # сборка в один файл dist/index.html
npm run check        # размер и отсутствие внешних запросов в сборке
```
Research-страницы открываются через любой статический сервер из корня проекта, например `python -m http.server 5173`, потом http://127.0.0.1:5173/research/.

Публикация: `npm run site` собирает `_site/` (главная, /play/, /demo/, /research/). Пуш в `main` → GitHub Actions сам выкладывает сайт: https://spisusha.github.io/stackball-save-the-kitty/ . Репозиторий публичный: https://github.com/spisusha/stackball-save-the-kitty . В этом репозитории git-автор — скрытый адрес GitHub (noreply), личную почту не использовать.

## Правила проекта
- Плейбл — один HTML без внешних запросов (никаких CDN, Google Fonts, внешних картинок).
- Звук только после первого касания, кнопка в магазин только на end card.
- Скриншоты из `research/refs/` принадлежат Azur Games: не публиковать, в git не добавлять.
- Везде подписывать, что это неофициальный концепт.
- В окружении Романа стоит хук GateGuard: перед первым созданием файла и первой командой он просит назвать факты (кто вызывает файл, данные, дословная просьба). Назови их и повтори действие.
- Отладка без видимого браузера: в плейбле есть `window.__sim(секунды, держать)` и `window.__danger()` — прогон симуляции и «опасен ли сектор под шаром» (только для проверки, на игру не влияют).
